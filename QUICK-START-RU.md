# Быстрый старт

Полная актуальная инструкция: [ПУБЛИКАЦИЯ.md](ПУБЛИКАЦИЯ.md).

1. Распакуйте ZIP.
2. Проверьте index.html.
3. Загрузите содержимое папки в корень GitHub-репозитория main.
4. Settings → Pages → GitHub Actions.
5. Проверьте файл .github/workflows/pages.yml и зелёный запуск Publish Nur.
6. Откройте опубликованный адрес.
7. Подтвердите URL prefix в Google Search Console и отправьте sitemap.xml.
