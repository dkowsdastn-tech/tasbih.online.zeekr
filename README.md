# Nur v10

Готовый статический сайт: онлайн тасбих, Сунна, знания и Коран.

**Начните с [ПУБЛИКАЦИЯ.md](ПУБЛИКАЦИЯ.md)** — подробная инструкция по GitHub Pages и Google Search Console.

## Запуск

Откройте index.html из распакованной папки. Для PWA и офлайн-кэша нужен HTTPS или localhost. При установленном Node.js можно запустить START-NUR.cmd.

## GitHub Pages

Загрузите содержимое папки в корень репозитория main, включая .github/workflows/pages.yml. В Settings → Pages выберите GitHub Actions. Публикация автоматически строит JS, создаёт sitemap и canonical для фактического адреса.

## Исходники

- index.html, css/styles.css, css/refined.css — интерфейс.
- js/app.js — поведение; js/enhancements.js — поиск, подписи и жесты.
- js/data.js — коллекции и знания; locales/*.json — переводы и Сунна.
- js/nur.bundle.js — готовая сборка без модульных импортов и сетевой загрузки переводов.
- build.cjs — пересборка: `node build.cjs` (пакеты не нужны).
- configure-seo.cjs — `node configure-seo.cjs https://ваш-адрес/`; выполняется автоматически в Actions.
- about.html — открытая страница помощи и объяснения тасбиха.
- sw.js — кэш публичных файлов только в пределах пути этого приложения.
- backend/, moderator.html — сохранённая серверная часть прежнего проекта. Не входит в публикацию GitHub Pages и не доступна через основные вкладки.

При изменениях кэшируемых файлов меняйте версию CACHE в sw.js и версии URL ресурсов согласованно в HTML и CORE. Не редактируйте bundle вручную; запускайте build.cjs.

Новые тексты доступны на русском и английском. В других языках новые материалы используют английский fallback; исходные переводы сохранены. Основные новые элементы управления дополнительно переведены на казахский и арабский.
