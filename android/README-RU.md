Проект использует Gradle 8.13, Android Gradle Plugin 8.13.2, JDK 17, SDK 36. В Android Studio выберите JDK 17+ и Gradle 8.13, установите Android SDK Platform 36. Лицензии SDK принимает владелец проекта. Затем выполните Sync и Build.

Для загрузки в Play Console: Build → Generate Signed App Bundle / APK → Android App Bundle. Создайте свой upload keystore, сохраните его и пароль в безопасном месте. Выберите release. Никому не отправляйте пароли в чат. Ключ и пароль в проект не включены.
